# 🛒 Simple Shopping List 

🛒 Simple Shopping List | برنامه مدیریت لیست خرید با پایتون


این یک برنامه ساده مدیریت لیست خرید است که با زبان برنامه‌نویسی Python نوشته شده است.


در این برنامه، کاربر می‌تواند نام کالاهای موردنظر خود را وارد کند و برنامه آن‌ها را داخل یک لیست ذخیره می‌کند. با وارد کردن عدد -1، دریافت کالاها متوقف شده و تمام کالاهای ثبت‌شده نمایش داده می‌شوند.


⚙️ How It Works




ابتدا یک لیست خالی با نام shop ایجاد می‌شود.


حلقه while True برنامه را به‌صورت مداوم اجرا می‌کند.


با استفاده از input() نام کالا از کاربر دریافت می‌شود.


اگر کاربر عدد -1 را وارد کند، پیام توقف نمایش داده می‌شود.


دستور break باعث خروج از حلقه می‌شود.


دستور append() کالای واردشده را به انتهای لیست اضافه می‌کند.


در پایان، دستور print() تمام کالاهای ذخیره‌شده را نمایش می‌دهد.




🛠️ Python Concepts Used




Variables


Lists (list)


While Loop (while)


User Input (input())


Conditional Statements (if)


Break Statement (break)


Append Method (append())


Print Function (print())
